# devproj1
🏋️ Gym Registration Page (First Frontend Project)
This project marks my first attempt at building a frontend interface using HTML and CSS. The goal was to design a simple and visually appealing registration form for a fictional gym or travel service, where users can enter their personal information and sign up for a program.

🔧 Features
Custom-styled form elements using pure CSS

Responsive layout structure

Navigation bar and header section

Stylish buttons with hover effects

Custom fonts from Google Fonts

Background image integration

Clean, organized structure with comments for learning

🎯 Purpose
This project was a hands-on learning experience to understand:

How to structure a webpage using HTML

How to apply CSS styling and layouts

Basics of web typography and user interface design

Practical use of margins, padding, positioning, and form design

Feel free to check the code and suggest improvements. This is just the beginning of my web development journey!
